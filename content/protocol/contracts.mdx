# Contracts and verification

Keycat writes no Solidity. Every contract below was written, audited and
deployed by its publisher; Keycat pins each address, checks its code hash
against the publisher's registry, and refuses to build an operation against
an address it has not verified.

## Check your business account

You need your business account's address (shown in the dashboard) and a Base
RPC URL. These commands use Foundry's
[`cast`](https://getfoundry.sh); any client that can make `eth_call` works.

```bash
SAFE=0xYourBusinessAccount
RPC=https://mainnet.base.org

# A Safe proxy pointing at SafeL2 1.4.1 (storage slot 0 holds the singleton)
cast storage $SAFE 0 --rpc-url $RPC
cast call $SAFE "VERSION()(string)" --rpc-url $RPC

# Owners and threshold
cast call $SAFE "getOwners()(address[])" --rpc-url $RPC
cast call $SAFE "getThreshold()(uint256)" --rpc-url $RPC

# Enabled modules: the 4337 module, plus your Roles modifier if savings is on
cast call $SAFE "getModulesPaginated(address,uint256)(address[],address)" \
  0x0000000000000000000000000000000000000001 10 --rpc-url $RPC
```

An account that has not run its first operation yet has no code, and these
calls return nothing; its address is still yours ([why](/protocol/account#a-counterfactual-address)).

Each owner is a passkey signer contract. Its configuration is your passkey's
public key, and the factory reproduces its address from that key alone:

```bash
OWNER=0xOneOfTheOwners
FACTORY=0x1d31F259eE307358a26dFb23EB365939E8641195

# cast annotates large numbers ("123… [1.2e76]"), so keep the first column
read X Y VERIFIERS < <(cast call $OWNER "getConfiguration()(uint256,uint256,uint176)" --rpc-url $RPC | awk '{print $1}' | xargs)
cast call $FACTORY "getSigner(uint256,uint256,uint176)(address)" $X $Y $VERIFIERS --rpc-url $RPC   # equals $OWNER
cast to-hex $VERIFIERS   # 0x100 followed by 40 zeros
```

`VERIFIERS` is `0x100 << 160`: the P-256 precompile at `0x100` in the top
16 bits and no fallback verifier in the low 160.

## Check the savings permission

With savings on, the second module is your Roles modifier. Its owner, avatar
and target are your Safe:

```bash
ROLES=0xYourRolesModifier
cast call $ROLES "owner()(address)" --rpc-url $RPC    # your Safe
cast call $ROLES "avatar()(address)" --rpc-url $RPC   # your Safe
cast call $ROLES "target()(address)" --rpc-url $RPC   # your Safe
```

The role's scope is set by the `scopeTarget`, `scopeFunction` and
`assignRoles` calls in the batch you signed to turn savings on; they are in
that transaction on any block explorer, and [Savings](/protocol/savings)
lists the conditions they set.

## Check a payout group

```bash
SPLIT=0xYourGroupSplit
cast call $SPLIT "owner()(address)" --rpc-url $RPC   # 0x0000…0000: nobody can change it
```

The split's recipients and allocations are in the `SplitCreated` event of the
transaction that created it.
