# Keycat docs

The source of [docs.keycat.net](https://docs.keycat.net): guides and reference
for taking payments with Keycat, and a technical section on the contracts,
signatures and permissions behind a Keycat business account.

The pages are MDX in [`content/`](./content), built with
[Nextra](https://nextra.site) as a static site.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static export in out/
```

Found something wrong or unclear? Tell us in
[Keycat's Discord](https://discord.gg/jwu6y3juEw).
